## 1. 文档处理类

### 1.1 批量Markdown文件整理

**适用场景**
整理散乱的Markdown文档并统一格式

**输入**
- 输入类型：多个Markdown文件（.md）
- 输入示例：`/docs/notes/*.md` 包含30个未格式化的笔记文件

**中间步骤**（5步）
1. 扫描目录，列出所有.md文件 - 使用 `Glob` 工具或 `find` 命令
2. 读取每个文件内容 - 使用 `Read` 工具批量读取
3. 分析文档结构（标题层级、列表格式、代码块） - AI分析
4. 应用统一格式规则（标题规范、段落间距、代码块语法高亮） - `Edit` 工具
5. 生成格式化后的文件和汇总报告 - `Write` 工具

**输出**
- 输出类型：格式化的Markdown文件 + 处理报告
- 输出示例：30个规范化的.md文件 + `formatting-report.md` 汇总文档

**关键提示词片段**（95字）
```
请帮我整理 /docs/notes/ 目录下的所有Markdown文件：
1. 统一标题层级（# 主标题，## 二级标题）
2. 规范列表格式（统一使用 - 或 1.）
3. 修复代码块语法高亮标记
4. 调整段落间距（标题前后空行）
5. 生成处理报告，列出每个文件的修改内容
```

**预估时间**
手动：120分钟 | 自动化：8分钟

**难度**
低

### 1.2 多文件信息提取与汇总

**适用场景**
从多个文档中提取关键信息并生成汇总

**输入**
- 输入类型：多种格式文档（.md/.txt/.log）
- 输入示例：10个项目会议记录文件，需要提取行动项和决策

**中间步骤**（4步）
1. 批量读取指定目录的文件 - `Glob` + `Read` 工具
2. 用AI提取关键信息（行动项、决策点、待办事项、责任人） - AI分析
3. 按类别或时间线组织提取的信息 - 数据结构化
4. 生成结构化汇总文档（表格或列表形式） - `Write` 工具

**输出**
- 输出类型：结构化汇总文档（Markdown/CSV）
- 输出示例：`meeting-summary.md` 包含所有行动项表格和决策时间线

**关键提示词片段**（88字）
```
从 /meetings/*.md 中提取关键信息并汇总：
1. 提取每次会议的行动项（任务、责任人、截止日期）
2. 提取重要决策点
3. 按时间顺序组织内容
4. 生成Markdown表格格式的汇总文档
5. 标注未完成的行动项
```

**预估时间**
手动：90分钟 | 自动化：5分钟

**难度**
中

## 2. 数据处理类

### 2.1 CSV数据清洗与分析

**适用场景**
清洗脏数据并生成统计分析报告

**输入**
- 输入类型：CSV文件
- 输入示例：`sales-data.csv` 包含5000行销售记录，存在缺失值和格式错误

**中间步骤**（5步）
1. 读取CSV文件 - `Read` 工具或Bash `cat`
2. 检测数据质量问题（缺失值、重复行、格式错误） - AI分析
3. 执行清洗操作（填充缺失值、去重、格式统一） - 数据处理
4. 生成统计分析（汇总、平均值、趋势） - AI计算
5. 输出清洗后的CSV和分析报告 - `Write` 工具

**输出**
- 输出类型：清洗后的CSV + Markdown分析报告
- 输出示例：`sales-data-cleaned.csv` + `analysis-report.md`（含统计图表建议）

**关键提示词片段**（92字）
```
清洗并分析 sales-data.csv：
1. 检测并报告数据质量问题（缺失值比例、重复行数）
2. 清洗：缺失值用中位数填充，删除重复行
3. 统一日期格式为 YYYY-MM-DD
4. 生成统计报告：总销售额、月度趋势、Top 10产品
5. 输出清洗后CSV和Markdown报告
```

**预估时间**
手动：150分钟 | 自动化：6分钟

**难度**
中

### 2.2 JSON数据结构化整理

**适用场景**
将复杂嵌套JSON转换为扁平化结构

**输入**
- 输入类型：JSON文件（嵌套结构）
- 输入示例：`api-response.json` 包含多层嵌套的API响应数据

**中间步骤**（4步）
1. 读取JSON文件并解析结构 - `Read` 工具 + AI解析
2. 提取需要的字段（支持嵌套路径如 `data.users[].profile.name`） - 数据提取
3. 转换为扁平化结构（CSV或简化JSON） - 数据重构
4. 保存为目标格式 - `Write` 工具

**输出**
- 输出类型：扁平化JSON或CSV
- 输出示例：`users-flat.csv` 包含提取的用户信息表格

**关键提示词片段**（86字）
```
将 api-response.json 扁平化并转换为CSV：
1. 提取字段：用户ID、姓名、邮箱、注册日期
2. 处理嵌套路径：data.users[].profile.*
3. 处理数组字段：tags转为逗号分隔字符串
4. 输出为CSV格式，包含表头
5. 报告处理的记录数
```

**预估时间**
手动：80分钟 | 自动化：3分钟

**难度**
中

### 2.3 文本数据批量处理与分类

**适用场景**

**关键提示词片段**（95字）

批量处理并分类 customer-feedback.csv：
1. 清洗文本：去除emoji、统一编码

3. 情感分析：正面/中性/负面
4. 添加分类和情感标签到新列
5. 生成统计报告：各类别数量、情感分布、关键词云

## 3. 内容创作类

### 3.1 结构化内容批量生成

**适用场景**
基于模板和数据源批量生成结构化内容

**输入**
- 输入类型：数据源（CSV/JSON）+ 内容模板

**中间步骤**（4步）
1. 读取数据源文件 - `Read` 工具
2. 解析内容模板（识别变量占位符） - 模板解析
3. 对每条数据应用模板，AI生成个性化内容 - AI生成

**输出**
- 输出类型：多个Markdown文件或单个汇总文档
- 输出示例：50个产品介绍文档（`product-001.md` ~ `product-050.md`）

**关键提示词片段**（98字）
```
基于 products.csv 批量生成产品介绍：
1. 读取产品信息（名称、价格、特性、规格）
2. 为每个产品生成150字介绍，包含：产品亮点、适用场景、核心优势
3. 使用Markdown格式，包含标题和列表
4. 保存为独立文件：product-{id}.md
5. 生成索引文件列出所有产品
```

手动：200分钟 | 自动化：7分钟

### 3.2 多版本内容批量创建

**适用场景**
同一内容生成多个版本（风格/长度/语言）

**输入**
- 输入类型：原始内容文件 + 版本需求列表
- 输入示例：`press-release.md`（新闻稿）需要生成：正式版/社交媒体版/简短版

**中间步骤**（4步）
1. 读取原始内容 - `Read` 工具
2. 定义各版本要求（字数、风格、格式） - 规格定义
3. AI改写生成各版本内容 - AI生成（保持核心信息一致）
4. 保存各版本文件 - `Write` 工具

**输出**
- 输出类型：多个版本的内容文件
- 输出示例：`press-release-formal.md`（500字）、`press-release-social.md`（280字符）、`press-release-brief.md`（100字）

**关键提示词片段**（93字）
```
基于 press-release.md 生成3个版本：
1. 正式版：500字，正式语气，完整信息
2. 社交媒体版：280字符以内，活泼语气，含话题标签
3. 简短版：100字，核心要点，适合邮件摘要
4. 保持核心事实一致
5. 各版本独立保存并生成对比表
```

**预估时间**
手动：120分钟 | 自动化：5分钟

**难度**
低
