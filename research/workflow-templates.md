## 1. 文档处理类

### 1.1 批量Markdown文件整理

**适用场景**
整理散乱的Markdown文档并统一格式

**输入**
- 输入类型：多个Markdown文件（.md）
- 输入示例：`/docs/notes/*.md` 包含30个未格式化的笔记文件

**中间步骤**（5步）
1. 扫描目录，列出所有.md文件 - 使用 `Glob` 工具或 `find` 命令
2. 读取每个文件内容 - 使用 `Read` 工具批量读取
3. 分析文档结构（标题层级、列表格式、代码块） - AI分析
4. 应用统一格式规则（标题规范、段落间距、代码块语法高亮） - `Edit` 工具
5. 生成格式化后的文件和汇总报告 - `Write` 工具

**输出**
- 输出类型：格式化的Markdown文件 + 处理报告
- 输出示例：30个规范化的.md文件 + `formatting-report.md` 汇总文档

**关键提示词片段**（95字）
```
请帮我整理 /docs/notes/ 目录下的所有Markdown文件：
1. 统一标题层级（# 主标题，## 二级标题）
2. 规范列表格式（统一使用 - 或 1.）
3. 修复代码块语法高亮标记
4. 调整段落间距（标题前后空行）
5. 生成处理报告，列出每个文件的修改内容
```

**预估时间**
手动：120分钟 | 自动化：8分钟

**难度**
低

### 1.2 多文件信息提取与汇总

**适用场景**
从多个文档中提取关键信息并生成汇总

**输入**
- 输入类型：多种格式文档（.md/.txt/.log）
- 输入示例：10个项目会议记录文件，需要提取行动项和决策

**中间步骤**（4步）
1. 批量读取指定目录的文件 - `Glob` + `Read` 工具
2. 用AI提取关键信息（行动项、决策点、待办事项、责任人） - AI分析
3. 按类别或时间线组织提取的信息 - 数据结构化
4. 生成结构化汇总文档（表格或列表形式） - `Write` 工具

**输出**
- 输出类型：结构化汇总文档（Markdown/CSV）
- 输出示例：`meeting-summary.md` 包含所有行动项表格和决策时间线

**关键提示词片段**（88字）
```
从 /meetings/*.md 中提取关键信息并汇总：
1. 提取每次会议的行动项（任务、责任人、截止日期）
2. 提取重要决策点
3. 按时间顺序组织内容
4. 生成Markdown表格格式的汇总文档
5. 标注未完成的行动项
```

**预估时间**
手动：90分钟 | 自动化：5分钟

**难度**
中

### 1.3 文档格式转换与增强

**适用场景**
将文档批量转换为其他格式并增强可读性

**输入**
- 输入类型：原始文档（.txt/.md/.log）
- 输入示例：5个纯文本日志文件，需转换为带格式的Markdown

**中间步骤**（4步）
1. 读取源文件内容 - `Read` 工具
2. 分析内容结构（识别标题、列表、代码段） - AI分析
3. 转换为目标格式并增强（添加目录、代码高亮、表格美化） - AI转换
4. 保存为新格式文件 - `Write` 工具

**输出**
- 输出类型：目标格式文档（Markdown/HTML/PDF）
- 输出示例：5个带格式的Markdown文档，包含自动生成的目录和代码高亮

**关键提示词片段**（82字）
```
将 /logs/*.txt 转换为Markdown格式并增强：
1. 识别日志中的时间戳、错误级别、消息内容
2. 转换为Markdown表格格式
3. 为错误级别添加颜色标记（emoji或badge）
4. 添加文档目录和统计摘要
5. 保存为 .md 文件
```

**预估时间**
手动：60分钟 | 自动化：4分钟

**难度**
低
