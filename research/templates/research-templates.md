# 研究类提示模板

## 模板R1：系统性调研框架

```
我需要对 [主题] 进行系统性调研。

**调研目标**：
[1-2句话描述你想了解什么]

**调研范围**：
- 领域/行业：[具体领域]
- 时间范围：[如最近3年]
- 地理范围：[如全球/中国/特定地区]

**输出要求**：
1. **概述**（100-200字）
   - 当前状态
   - 主要趋势
   - 关键数据

2. **关键发现**（5-8条）
   - 每条包含：发现 + 数据支持 + 来源

3. **细分领域分析**（3-5个细分）
   - 每个细分包含：定义、现状、机会

4. **关键资源清单**（10-15个）
   - 格式：名称 + 链接 + 1句话描述

5. **结论与建议**（3-5条可执行建议）

**注意事项**：
- 使用权威来源
- 标注不确定的信息
- 避免过时信息（2年以上）

请按以上结构完成调研。
```

**适用场景**：市场调研、技术调研、行业分析
**预计耗时**：15-30分钟
**输出长度**：2000-4000字

## 模板R2：竞品快速分析

```
请帮我分析以下竞品：

**竞品信息**：
- 竞品1：[名称/链接]
- 竞品2：[名称/链接]
- 竞品3：[名称/链接]
- [更多竞品...]

**分析维度**：
1. 核心功能对比
2. 定价策略
3. 目标用户
4. 差异化卖点
5. 优势与不足

**输出格式**：

### 快速对比表

| 维度 | 竞品1 | 竞品2 | 竞品3 |
|------|-------|-------|-------|
| 核心功能 | | | |
| 定价 | | | |
| 目标用户 | | | |
| 主要卖点 | | | |
| 优势 | | | |
| 不足 | | | |

### 详细分析（每个竞品150-200字）

### 机会点识别（3-5个）
基于竞品分析，我们的产品可以在以下方面差异化...

请访问这些网站并完成分析。
```

**适用场景**：产品竞品分析、市场定位
**预计耗时**：10-20分钟
**输出长度**：1000-2000字

## 模板R3：信息提取与整理

```
我有以下内容需要提取关键信息：

[粘贴文章/文档/网页内容]

**提取要求**：

1. **核心观点**（3-5个）
   - 用1句话概括每个观点

2. **关键数据**（所有数字、百分比、日期）
   - 格式：数据 + 上下文

3. **重要术语**（5-10个）
   - 格式：术语 + 定义

4. **可执行建议**（如果有）
   - 具体的行动步骤

5. **相关资源**（如果提到）
   - 人名、公司名、产品名、链接等

6. **个人笔记**
   - 对我的启发（3条）
   - 需要进一步研究的点（2条）

**输出格式**：Markdown，便于保存到笔记

请按以上结构提取信息。
```

**适用场景**：文章阅读、会议记录、视频笔记
**预计耗时**：5-10分钟
**输出长度**：500-1000字

## 模板R4：Claude Code专用 - 多源信息汇总

```
请帮我创建一个新分支 `research-[主题名称]`，然后完成以下调研：

**在项目中创建文件**：`research/[主题]-summary.md`

**调研任务**：
收集关于 [主题] 的信息，包括：
1. [维度1] - 例如：定义和概念
2. [维度2] - 例如：应用场景
3. [维度3] - 例如：工具/方法
4. [维度4] - 例如：案例/示例
5. [维度5] - 例如：学习资源

**信息来源**（选择适用的）：
- [ ] 搜索引擎（限2-3次）
- [ ] 已知知识
- [ ] 特定网站：[列出网站]

**输出结构**：

# [主题] 研究报告

## 1. 概述（100-200字）

## 2. [维度1]
- 要点1
- 要点2
...

## 3. [维度2]
[内容]

## 4. [维度3]
[内容]

## 5. [维度4]
[内容]

## 6. [维度5]
[内容]

## 7. 参考资源（10-15个）
- [资源1] - [链接] - [1句话描述]
- [资源2] - [链接] - [1句话描述]
...

## 8. 关键结论（3-5条）

**执行要求**：
- 分步执行，每完成一个维度就保存文件
- 如遇网络限制，使用已知信息
- 完成后创建Pull Request

开始执行。
```

**适用场景**：Claude Code长篇调研
**预计耗时**：20-40分钟
**输出长度**：3000-5000字

## 模板R5：趋势分析模板

```
请分析 [领域/主题] 的发展趋势。

**分析框架**：

1. **历史回顾**（2-3年）
   - 关键里程碑
   - 重要变化

2. **当前状态**（2024年）
   - 主流做法
   - 主要参与者
   - 市场规模（如有数据）

3. **未来趋势**（1-3年预测）
   - 趋势1：[趋势名] - [描述] - [支撑证据]
   - 趋势2：[趋势名] - [描述] - [支撑证据]
   - 趋势3：[趋势名] - [描述] - [支撑证据]
   - [更多趋势...]

4. **机会与挑战**
   - 机会：[3-5个]
   - 挑战：[3-5个]

5. **对我的影响**
   - 应该关注什么
   - 应该学习什么
   - 应该准备什么

**输出要求**：
- 每个趋势提供至少1个数据或案例支撑
- 明确区分"确定的趋势"和"可能的趋势"
- 给出具体的时间线预测

请完成分析。
```

**适用场景**：技术趋势、市场趋势、行业发展
**预计耗时**：15-25分钟
**输出长度**：1500-2500字
