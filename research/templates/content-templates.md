# 内容创作类提示模板

## 模板W1：长文写作框架

```
请帮我写一篇关于 [主题] 的文章。

**文章类型**：[教程/观点文/案例分析/综述/其他]

**目标读者**：
- 身份：[如设计师/开发者/创业者]
- 背景：[有XX基础/对XX感兴趣]
- 需求：[想了解XX/想学习XX/想解决XX问题]

**核心观点/信息**：
[1-3句话，你想传达的核心内容]

**文章结构**：
1. **引言**（200字）
   - 吸引注意的开场
   - 说明问题/背景
   - 预告文章价值

2. **主体**（分3-5个小节，每节300-500字）
   - 小节1：[主题]
   - 小节2：[主题]
   - 小节3：[主题]
   - [更多小节...]

3. **结论**（150-200字）
   - 总结要点
   - 可执行建议
   - 号召行动

**写作要求**：
- 总字数：[1500-2000字 / 其他]
- 语气：[专业/轻松/激励性/其他]
- 语言：[中文/英文]
- 包含：[案例X个 / 数据X个 / 图片建议X处]

**特别注意**：
- [避免XX术语 / 使用简单语言]
- [包含具体示例]
- [提供可执行步骤]

请按以上结构写作。
```

**适用场景**：博客文章、教程、分析文章
**预计耗时**：15-30分钟
**输出长度**：1500-3000字

## 模板W2：教程/指南创建器

```
请帮我创建一个 [技能/工具/流程] 的教程。

**教程主题**：[具体主题]

**学习者水平**：[零基础/初级/中级/高级]

**教程目标**：
学完后，学习者能够：
1. [具体技能1]
2. [具体技能2]
3. [具体技能3]

**教程结构**：

### 第0部分：准备工作
- 需要的工具/软件
- 前置知识
- 预计学习时间

### 第1部分：基础概念（200-300字）
- 核心概念解释
- 为什么重要
- 应用场景

### 第2部分：步骤详解
**步骤1：[步骤名]**
- 目标：[这步要达成什么]
- 操作：[具体怎么做]
- 截图/代码：[如果需要]
- 常见问题：[可能遇到的问题+解决方法]

**步骤2：[步骤名]**
[同上格式]

[更多步骤...]

### 第3部分：实践练习
- 练习1：[描述]
- 练习2：[描述]
- 参考答案

### 第4部分：进阶资源
- 深入学习资源
- 相关工具
- 常见问题FAQ

**写作要求**：
- 使用简单语言
- 每步都有清晰的操作指令
- 提供实际示例
- 包含疑难排查

请创建完整教程。
```

**适用场景**：技能教学、工具使用指南、流程说明
**预计耗时**：20-40分钟
**输出长度**：2000-4000字

## 模板W3：内容翻译+本地化

```
请帮我翻译以下内容，并进行本地化调整。

**源语言**：[中文/英文]
**目标语言**：[英文/中文]

**内容类型**：[技术文档/营销文案/教程/其他]

**源内容**：
[粘贴要翻译的内容]

**翻译要求**：
1. **准确性**
   - 专业术语使用标准译法
   - 保持原意不变

2. **本地化**
   - 使用目标语言的表达习惯
   - 调整文化相关内容（如示例、比喻）
   - 数字、日期格式本地化

3. **风格**
   - 保持原文的语气风格
   - [正式/轻松/技术性] 的语言

4. **格式**
   - 保持原文的Markdown格式
   - 保持标题层级
   - 保留代码块、链接

**请提供**：
1. 完整翻译
2. 关键术语对照表（如果有）
3. 需要注意的文化差异点（如果有）

开始翻译。
```

**适用场景**：文档翻译、产品国际化、内容本地化
**预计耗时**：10-30分钟（取决于长度）
**输出**：翻译后的内容+术语表

## 模板W4：社交媒体内容生成

```
请帮我为 [产品/服务/内容] 创建社交媒体内容。

**目标平台**：[Twitter / 小红书 / LinkedIn / 其他]

**内容主题**：[具体主题]

**营销目标**：[品牌曝光/引流/教育/销售]

**目标受众**：
- 身份：[如设计师/创业者]
- 兴趣点：[他们关心什么]
- 痛点：[他们的问题]

**内容要求**：
生成 [5-10] 条内容，每条包括：

1. **主文案**
   - 长度：[140字/500字/其他]
   - 语气：[专业/轻松/激励/其他]
   - 包含：[CTA / 问题 / 数据 / 其他]

2. **标签**（如适用）
   - 3-5个相关标签

3. **配图建议**
   - 描述建议的配图类型

4. **发布时机建议**

**风格参考**：
[可选：提供1-2个你喜欢的内容示例]

**避免**：
- [过度营销语言]
- [敏感话题]
- [其他要避免的]

请生成内容。
```

**适用场景**：社交媒体运营、内容营销
**预计耗时**：10-15分钟
**输出**：5-10条可用的社交媒体内容
