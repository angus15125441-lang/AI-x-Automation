# 商业类提示模板

## 模板B1：商业方案设计

```
请帮我设计一个 [业务/产品/服务] 的商业方案。

**基本信息**：
- 方案名称：[名称]
- 目标：[要达成什么目标]
- 预算：[如果有限制]
- 时间线：[如3个月/1年]

**方案要求**：

### 1. 背景与目标（200字）
- 当前状况
- 要解决的问题
- 预期成果

### 2. 目标市场分析（300字）
- 目标用户画像
- 市场规模估算
- 竞争态势

### 3. 解决方案（400字）
- 核心方案描述
- 实施步骤（分阶段）
- 关键资源需求

### 4. 商业模式（300字）
- 收入来源
- 成本结构
- 盈利路径

### 5. 执行计划（300字）
- 时间表（里程碑）
- 责任分工（如果是团队）
- 风险预案

### 6. 财务预测（简化版）
- 启动成本
- 月度运营成本
- 收入预期（3-12个月）
- 盈亏平衡点

### 7. 成功指标（KPIs）
- 3-5个关键指标
- 目标数值
- 监测频率

请按以上结构提供完整方案。
```

**适用场景**：新项目策划、业务提案、投资方案
**预计耗时**：20-30分钟
**输出长度**：1500-2500字

## 模板B2：合同比对分析

```
请帮我比对以下合同/协议的关键条款。

**合同A**：[名称/类型]
[粘贴合同A内容，或提供文件路径]

**合同B**：[名称/类型]
[粘贴合同B内容，或提供文件路径]

**比对重点**：
1. 价格/费用条款
2. 服务/产品范围
3. 时间/期限
4. 责任与义务
5. 违约/终止条款
6. 知识产权
7. [其他关注点]

**输出要求**：

### 对比表

| 条款类别 | 合同A | 合同B | 差异分析 |
|---------|-------|-------|---------|
| 价格/费用 | | | |
| 服务范围 | | | |
| 期限 | | | |
| 责任义务 | | | |
| 违约条款 | | | |
| [其他] | | | |

### 关键差异点（3-5个）
1. [差异1] - 影响：[说明对我的影响]
2. [差异2] - 影响：[说明对我的影响]
...

### 风险提示（2-3个）
- 合同A的风险：[说明]
- 合同B的风险：[说明]

### 建议
- 更有利的选择：[A/B，说明原因]
- 建议谈判的点：[2-3个]
- 需要补充的条款：[如果有]

请完成比对分析。
```

**适用场景**：合同审查、协议对比、条款分析
**预计耗时**：15-25分钟
**输出长度**：1000-2000字

## 模板B3：决策分析框架

```
我需要在以下选项中做决策，请帮我系统分析。

**决策主题**：[要决策的事项]

**选项**：
- 选项A：[描述]
- 选项B：[描述]
- 选项C：[描述]
- [更多选项...]

**评估维度**（重要性权重）：
1. [维度1，如成本] - 权重：[30%]
2. [维度2，如时间] - 权重：[25%]
3. [维度3，如风险] - 权重：[20%]
4. [维度4，如收益] - 权重：[15%]
5. [维度5，如其他] - 权重：[10%]

**约束条件**：
- [约束1，如预算上限]
- [约束2，如时间限制]
- [其他约束]

**分析要求**：

### 1. 选项对比矩阵

| 维度 | 选项A | 选项B | 选项C |
|------|-------|-------|-------|
| 维度1 | 评分+说明 | | |
| 维度2 | | | |
| 维度3 | | | |
| 维度4 | | | |
| 维度5 | | | |
| **加权总分** | | | |

### 2. 优劣势分析

**选项A**
- 优势：[3条]
- 劣势：[3条]
- 风险：[2条]

[对其他选项重复]

### 3. 场景分析
- 最好情况：选[X]，因为...
- 最坏情况：选[X]，因为...
- 最可能情况：选[X]，因为...

### 4. 推荐决策
- 推荐：[选项X]
- 理由：[3-5条]
- 实施建议：[2-3条]
- 风险缓解：[如何降低该选项的风险]

请完成分析。
```

**适用场景**：多选项决策、供应商选择、策略选择
**预计耗时**：15-20分钟
**输出长度**：1000-1500字

## 模板B4：SWOT分析生成器

```
请帮我对 [公司/产品/项目/个人] 进行SWOT分析。

**分析对象**：[具体名称]

**背景信息**：
- 当前状况：[简要描述]
- 所处行业/领域：[说明]
- 关键利益相关者：[客户/竞争对手/合作伙伴]

**分析维度**：

### Strengths（优势）
列出5-8个内部优势：
1. [优势1] - [具体说明]
2. [优势2] - [具体说明]
...

### Weaknesses（劣势）
列出5-8个内部劣势：
1. [劣势1] - [具体说明]
2. [劣势2] - [具体说明]
...

### Opportunities（机会）
列出5-8个外部机会：
1. [机会1] - [具体说明]
2. [机会2] - [具体说明]
...

### Threats（威胁）
列出5-8个外部威胁：
1. [威胁1] - [具体说明]
2. [威胁2] - [具体说明]
...

### 策略建议

**SO策略（利用优势抓住机会）**
- 策略1：[具体策略]
- 策略2：[具体策略]

**WO策略（克服劣势抓住机会）**
- 策略1：[具体策略]
- 策略2：[具体策略]

**ST策略（利用优势应对威胁）**
- 策略1：[具体策略]
- 策略2：[具体策略]

**WT策略（最小化劣势和威胁）**
- 策略1：[具体策略]
- 策略2：[具体策略]

### 行动优先级（Top 3）
1. [行动1] - 预期效果 - 时间线
2. [行动2] - 预期效果 - 时间线
3. [行动3] - 预期效果 - 时间线

请完成SWOT分析。
```

**适用场景**：战略规划、项目评估、个人发展
**预计耗时**：15-25分钟
**输出长度**：1500-2000字
