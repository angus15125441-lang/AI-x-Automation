# 编码类提示模板

## 模板C1：Python脚本生成器

```
请帮我创建一个Python脚本，功能如下：

**功能描述**：
[1-2句话描述脚本要做什么]

**输入**：
- 输入类型：[文件/命令行参数/API数据/其他]
- 输入格式：[具体格式]
- 输入示例：[提供一个示例]

**处理逻辑**：
1. [步骤1]
2. [步骤2]
3. [步骤3]
...

**输出**：
- 输出类型：[文件/打印/API响应/其他]
- 输出格式：[具体格式]
- 输出示例：[提供一个示例]

**其他要求**：
- 错误处理：[如何处理错误情况]
- 依赖库：[偏好使用的库，或"使用标准库"]
- 性能要求：[如果有]

**文件信息**：
- 文件名：[script_name.py]
- 保存路径：[路径，如 /home/claude/scripts/]

请创建完整的脚本，包括：
1. 必要的import
2. 函数定义（带docstring）
3. 主函数
4. 错误处理
5. 使用示例（注释）

创建后请说明如何使用。
```

**适用场景**：自动化脚本、数据处理、工具开发
**预计耗时**：5-15分钟
**输出**：完整可运行的Python脚本

## 模板C2：代码调试助手

```
我的代码出现了问题，请帮我调试。

**代码**：
[粘贴你的代码]

**问题描述**：
[描述出现的问题，如报错信息、意外行为等]

**预期行为**：
[描述代码应该做什么]

**已尝试的解决方案**：
- [尝试1]
- [尝试2]
...

**请帮我**：
1. 识别问题根源
2. 解释为什么会出现这个问题
3. 提供修复后的代码
4. 说明修改了什么

**如果可能，请提供**：
- 更好的实现方式
- 潜在的边界情况
- 性能优化建议
```

**适用场景**：代码debug、性能优化、重构
**预计耗时**：5-10分钟
**输出**：问题分析+修复代码

```
请帮我处理以下数据文件：

**输入文件**：
- 路径：[/path/to/input.csv 或 .json]
- 格式：[CSV/JSON/其他]
- 大致内容：[描述数据结构和字段]

**处理任务**：
1. [任务1，如：过滤出满足XX条件的行]
2. [任务2，如：计算XX字段的平均值]
3. [任务3，如：按XX字段分组统计]
4. [任务4，如：添加新字段XX]
...

**输出文件**：
- 路径：[/path/to/output.csv 或 .json]
- 格式：[期望的格式]

**其他要求**：
- 处理空值：[如何处理]
- 数据验证：[需要验证什么]
- 日志：[是否需要处理日志]

请创建脚本并执行处理。
```

**适用场景**：数据清洗、格式转换、统计分析
**预计耗时**：10-20分钟
**输出**：处理脚本+处理后的数据文件

## 模板C5：Claude Code专用 - 项目初始化

```
请帮我创建一个 [项目类型] 项目。

**项目信息**：
- 项目名：[project-name]
- 路径：[/home/claude/projects/project-name/]
- 类型：[Python/JavaScript/其他]

**项目结构**：
```
project-name/
├── src/               # 源代码
├── tests/             # 测试文件
├── data/              # 数据文件
│   ├── input/
│   └── output/
├── docs/              # 文档
├── scripts/           # 工具脚本
├── README.md          # 项目说明
├── requirements.txt   # Python依赖
└── .gitignore         # Git忽略
```

**包含文件**：
1. README.md - 包含：项目介绍、安装说明、使用方法
2. requirements.txt - 包含：[列出需要的Python包]
3. main.py / index.js - 基础入口文件
4. [其他需要的文件]

**请执行**：
1. 创建完整的目录结构
2. 创建所有必需文件（带基础内容）
3. 初始化git仓库
4. 提供项目使用说明

开始创建。
```

**适用场景**：新项目搭建、项目模板
**预计耗时**：5-10分钟
**输出**：完整的项目结构+文件
