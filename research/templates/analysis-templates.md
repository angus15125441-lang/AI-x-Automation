# 分析类提示模板

## 模板A1：数据分析报告

```
请帮我分析以下数据并生成报告。

**数据来源**：
- 数据文件：[文件路径或粘贴数据]
- 数据类型：[CSV / JSON / 数据库导出 / 其他]
- 时间范围：[如2024年1-10月]

**数据字段说明**：
- 字段1：[字段名] - [含义]
- 字段2：[字段名] - [含义]
- [更多字段...]

**分析目标**：
[1-2句话描述想从数据中了解什么]

**分析要求**：

### 1. 数据概览
- 数据量：记录数、时间跨度
- 数据质量：缺失值、异常值情况
- 主要统计指标：平均值、中位数、标准差等

### 2. 关键发现（5-8个）
- 发现1：[描述] + [数据支撑]
- 发现2：[描述] + [数据支撑]
...

### 3. 趋势分析
- 时间趋势：[如果有时间序列数据]
- 相关性分析：[字段间的关系]
- 异常检测：[识别异常模式]

### 4. 可视化建议（3-5个图表）
- 图表1：[类型] - 展示 [什么]
- 图表2：[类型] - 展示 [什么]
...

### 5. 结论与建议
- 主要结论：[3-5条]
- 可执行建议：[3-5条]
- 需要进一步分析的点：[2-3条]

请完成分析。
```

**适用场景**：业务数据分析、用户行为分析、财务数据分析
**预计耗时**：20-30分钟
**输出长度**：1500-2500字

## 模板A2：文本情感分析

```
请对以下文本进行情感和内容分析。

**文本来源**：
[粘贴文本内容，如：用户评论、反馈、社交媒体内容等]

**文本数量**：[约XX条]

**分析维度**：

### 1. 整体情感分布
- 正面：[百分比] - [数量]
- 中性：[百分比] - [数量]
- 负面：[百分比] - [数量]

### 2. 关键主题识别（Top 5-10）
- 主题1：[主题名] - 提及次数 - 主要情感
- 主题2：[主题名] - 提及次数 - 主要情感
...

### 3. 高频关键词（Top 20）
按类别整理：
- 产品/功能词：[列表]
- 情感词：[列表]
- 问题词：[列表]

### 4. 典型样本（各选3-5条）
- 典型正面评价：
  1. [样本] - [分析]
  2. [样本] - [分析]

- 典型负面反馈：
  1. [样本] - [分析]
  2. [样本] - [分析]

### 5. 洞察与建议
- 用户最满意的点：[3条]
- 用户最不满的点：[3条]
- 改进建议：[3-5条]
- 机会点：[2-3条]

请完成分析。
```

**适用场景**：用户反馈分析、评论分析、舆情监测
**预计耗时**：15-25分钟
**输出长度**：1000-2000字

## 模板A3：对比分析框架

```
请对以下对象进行系统性对比分析。

**对比对象**：
- 对象A：[名称/描述]
- 对象B：[名称/描述]
- [对象C：如果有]

**对比目的**：
[说明为什么要对比这些对象，想得出什么结论]

**对比维度**：
1. [维度1，如功能/性能]
2. [维度2，如价格/成本]
3. [维度3，如用户体验]
4. [维度4，如生态系统]
5. [维度5，如其他]

**分析要求**：

### 1. 对比矩阵

| 维度 | 对象A | 对象B | 对象C |
|------|-------|-------|-------|
| 维度1 | [详细描述] | | |
| 维度2 | | | |
| 维度3 | | | |
| 维度4 | | | |
| 维度5 | | | |

### 2. 详细对比（每个维度）

**维度1：[名称]**
- 对象A：[详细分析 100-150字]
- 对象B：[详细分析 100-150字]
- [对象C...]
- 小结：[谁更好，为什么]

[对其他维度重复]

### 3. 优劣势总结

**对象A**
- 突出优势：[3条]
- 主要劣势：[3条]
- 适用场景：[2-3个]

[对其他对象重复]

### 4. 相似点与差异点
- 相似点：[3-5个]
- 核心差异：[3-5个]

### 5. 选择建议
- 如果 [场景1]，选择 [对象X]，因为...
- 如果 [场景2]，选择 [对象Y]，因为...
- 如果 [场景3]，选择 [对象Z]，因为...

请完成对比分析。
```

**适用场景**：产品对比、技术选型、方案比较
**预计耗时**：20-30分钟
**输出长度**：1500-2500字

## 模板A4：根因分析（5 Whys）

```
请帮我分析以下问题的根本原因。

**问题描述**：
[详细描述遇到的问题或异常现象]

**问题影响**：
- 影响范围：[谁/什么受到影响]
- 影响程度：[轻微/中等/严重]
- 发生频率：[偶尔/经常/持续]

**背景信息**：
- 何时开始：[时间]
- 相关环境：[系统/流程/团队等]
- 已知条件：[任何可能相关的信息]

**分析方法：5 Whys**

**第1个Why：为什么会出现这个问题？**
- 直接原因：[描述]
- 支撑证据：[观察到的现象]

**第2个Why：为什么会有这个直接原因？**
- 更深层原因：[描述]
- 支撑证据：[分析或数据]

**第3个Why：为什么会有这个更深层原因？**
- 继续深挖：[描述]
- 支撑证据：[分析或数据]

**第4个Why：为什么会这样？**
- 系统性原因：[描述]
- 支撑证据：[分析或数据]

**第5个Why：根本原因是什么？**
- 根本原因：[描述]
- 支撑证据：[分析或数据]

### 根因分析总结

**识别出的根本原因**（1-3个）：
1. [根因1] - [详细说明]
2. [根因2] - [详细说明]
...

**因果链**：
[问题] ← [原因1] ← [原因2] ← [原因3] ← [根本原因]

### 解决方案

**短期措施**（应急处理，1-3条）：
1. [措施1] - 预期效果 - 实施时间
2. [措施2] - 预期效果 - 实施时间

**长期措施**（根治方案，2-4条）：
1. [措施1] - 解决的根因 - 实施计划
2. [措施2] - 解决的根因 - 实施计划

**预防措施**（避免复发，2-3条）：
1. [措施1]
2. [措施2]

### 实施计划

| 措施 | 负责人 | 时间线 | 优先级 | 成功指标 |
|------|--------|--------|--------|----------|
| [措施1] | | | 高/中/低 | |
| [措施2] | | | | |

请完成根因分析。
```

**适用场景**：问题诊断、事故分析、流程改进
**预计耗时**：15-25分钟
**输出长度**：1000-2000字
