# Claude Code 限制清单

## 技术限制

### 执行环境限制

#### 1. 网络访问
- **限制**：只能访问白名单域名
- **影响**：不能直接爬取大部分网站或调用未授权的API
- **替代方案**：
  - 手动提供网页内容
  - 使用已授权的API
  - 通过WebFetch工具访问（如可用）
  - 在本地下载后再处理
- **已知可访问域名示例**：
  - api.anthropic.com
  - github.com
  - pypi.org
  - npmjs.com
  - 各类文档站点

#### 2. 文件大小
- **限制**：
  - 单文件建议<1MB（超大文件会被截断）
  - 单行字符限制：2000字符
  - PDF文件：最大32MB，每次请求最多100页
  - 总行数有限制（具体视文件而定）
- **影响**：不适合处理大型数据文件、日志文件、大型JSON等
- **替代方案**：
  - 分批处理（读取部分行）
  - 使用流式读取
  - 拆分大文件为多个小文件
  - 使用offset和limit参数分段读取

#### 3. 执行时间
- **限制**：
  - 默认超时：2分钟
  - 最长超时：10分钟（可配置）
  - 长时间运行可能超时或被中断
- **影响**：不适合耗时任务（如大规模爬虫、长时间计算、大量文件处理）
- **替代方案**：
  - 分解为多个小任务
  - 保存中间结果
  - 使用批处理策略
  - 后台执行（run_in_background）但会话结束时终止

#### 4. 并发限制
- **限制**：
  - 工具调用是串行的（一个接一个）
  - 单个命令内可以用&或&&链接多个操作
  - 不能真正并行执行多个独立任务
- **影响**：串行执行效率较低，大批量任务耗时
- **替代方案**：
  - 在单个Bash命令中使用&实现伪并发
  - 优化任务顺序
  - 设计高效的批量处理流程

#### 5. 持久化
- **限制**：
  - 无法运行持久化后台服务
  - 会话结束时所有进程终止
  - 没有数据库服务（除非已安装并启动）
- **影响**：
  - 不能做持续监听任务
  - 不能做定时任务
  - 不能运行Web服务器供长期访问
- **替代方案**：
  - 使用外部cron服务
  - 使用云服务（如AWS Lambda）
  - 生成配置文件供用户手动部署
  - 使用systemd等系统服务（需要权限）

#### 6. 计算资源限制
- **限制**：
  - GPU算力有限（按小时滚动窗口和每周分配上限）
  - CPU和内存受限
  - 不适合计算密集型任务
- **影响**：
  - 机器学习训练受限
  - 大规模数据处理可能卡顿
  - 复杂算法可能超时
- **替代方案**：
  - 使用云端计算平台
  - 简化算法
  - 使用采样而非全量数据
  - 生成代码供用户在本地运行

### 文件操作限制

#### 1. 二进制文件
- **限制**：不能编辑图片、音视频、Office文件等二进制内容
- **影响**：
  - 无法做图像处理（裁剪、滤镜等）
  - 无法视频剪辑或音频编辑
  - 无法直接修改.docx、.xlsx、.pptx
- **替代方案**：
  - 调用外部工具API（如ImageMagick、FFmpeg）
  - 使用在线服务API
  - 对于Office文件，先转换为XML或其他文本格式
  - 生成处理脚本供用户执行

#### 2. 文件权限
- **限制**：
  - 某些系统文件无法访问
  - sudo权限受限
  - 不能修改系统核心配置
- **影响**：
  - 不能安装某些需要系统权限的软件
  - 不能修改/etc/下的配置
  - 不能修改系统级环境变量
- **替代方案**：
  - 操作用户目录文件
  - 使用用户级包管理（如pip --user）
  - 修改用户级配置文件（~/.bashrc等）
  - 生成说明供用户手动执行需要权限的操作

#### 3. 格式支持
- **限制**：
  - 不能直接处理Office文件（.docx, .xlsx, .pptx）
  - 某些专有格式不支持
  - 压缩文件需要先解压
- **影响**：需要格式转换的额外步骤
- **替代方案**：
  - 使用转换库（python-docx、openpyxl等）
  - 使用在线转换API
  - 让用户导出为CSV、JSON等标准格式
  - 读取Office文件的XML结构

#### 4. 文件编辑方式
- **限制**：
  - Edit工具只能精确字符串替换
  - 如果old_string不唯一会失败
  - 不支持正则表达式替换（通过Edit工具）
- **影响**：某些复杂编辑需要多步操作
- **替代方案**：
  - 使用replace_all批量替换
  - 提供更多上下文使old_string唯一
  - 使用sed/awk等工具（通过Bash）
  - 读取→修改→写入整个文件

### 代码执行限制

#### 1. 包管理
- **限制**：
  - 第三方库需要手动安装
  - 某些包可能因为系统依赖无法安装
  - 安装可能需要时间和网络
- **影响**：不能直接使用所有Python/Node包
- **替代方案**：
  - 先安装再使用（pip install、npm install）
  - 使用标准库替代
  - 生成requirements.txt供用户安装
  - 检查是否已安装

#### 2. 交互式命令
- **限制**：
  - 不支持需要用户输入的交互式命令
  - 如git rebase -i、vim、nano等
  - 无法处理提示输入密码的情况
- **影响**：某些高级Git操作受限，某些工具无法使用
- **替代方案**：
  - 使用非交互式参数
  - 预先配置（如git config）
  - 使用-y或--yes跳过确认
  - 通过环境变量传递凭证

#### 3. 资源限制
- **限制**：
  - 内存有限
  - CPU有限
  - 无GPU加速（或GPU使用受限）
- **影响**：不适合计算密集型任务
- **替代方案**：
  - 简化算法（如使用近似算法）
  - 减小数据规模
  - 使用云端计算
  - 生成代码供用户在更强机器上运行

#### 4. 调试限制
- **限制**：
  - 无法使用交互式调试器（如pdb、ipdb）
  - 无法设置断点逐步调试
  - 错误信息可能不完整
- **影响**：复杂bug可能难以定位
- **替代方案**：
  - 使用print/logging调试
  - 分段执行代码
  - 单元测试
  - 分析traceback和日志

### Web交互限制

#### 1. 域名白名单
- **限制**：大部分网站无法直接访问
- **影响**：
  - 不能爬取任意网站
  - 不能调用大多数公开API（除非在白名单）
  - 不能下载任意资源
- **替代方案**：
  - 使用WebFetch工具（如可用）
  - 用户手动提供内容
  - 使用已授权的API
  - 检查域名是否在白名单

#### 2. 访问速度
- **限制**：网络请求可能较慢或超时
- **影响**：
  - 大文件下载可能失败
  - 多次请求耗时长
  - API调用可能超时
- **替代方案**：
  - 设置重试机制（指数退避）
  - 增加超时时间
  - 使用缓存避免重复请求
  - 批量请求合并

#### 3. 认证和授权
- **限制**：
  - API密钥需要在环境中配置
  - 某些认证方式可能不支持（如OAuth流程）
  - 敏感信息管理受限
- **影响**：某些需要复杂认证的API难以使用
- **替代方案**：
  - 使用环境变量传递密钥
  - 简化认证流程
  - 使用token而非密码
  - 让用户在本地配置认证

### 跨文件依赖限制 *（来源：官方文档）*

#### 1. 大型项目理解
- **限制**：
  - 在大型项目中可能遗漏跨文件依赖
  - 可能误解模块级逻辑
  - 不能一次性理解所有代码
- **影响**：
  - 修改可能破坏其他模块
  - 重构可能不完整
  - 依赖关系可能被忽略
- **替代方案**：
  - 明确指出相关文件和依赖
  - 分步骤进行修改和验证
  - 使用Task工具进行代码探索
  - 提供架构文档或依赖图

#### 2. 领域知识限制 *（来源：官方文档）*
- **限制**：
  - 不能替代特定领域的专业知识
  - 遵循编程模式但不理解业务逻辑（除非明确说明）
  - 可能建议看似正确但有边界情况错误的代码
  - 可能引入微妙的bug
- **影响**：关键业务逻辑需要人工审查
- **替代方案**：
  - 详细说明业务规则
  - 提供测试用例
  - 代码审查
  - 明确边界条件

### Token使用限制

#### 1. 上下文窗口
- **限制**：
  - Token总量有限（当前预算：200000）
  - 大量文件读取会快速消耗token
  - 长对话可能达到上限
- **影响**：
  - 不能一次性处理大量文件
  - 复杂任务可能需要多个会话
  - 历史对话可能被截断
- **替代方案**：
  - 分批处理文件
  - 新会话继续任务
  - 只读取必要部分
  - 使用Task工具（独立token预算）

#### 2. 输出截断
- **限制**：
  - 命令输出>30000字符会截断
  - 文件读取有行数限制
- **影响**：大文件或大量输出看不全
- **替代方案**：
  - 使用head/tail限制输出
  - 分段读取文件
  - 将输出保存到文件
  - 使用grep等过滤工具

## 使用场景限制

### 不适合的场景

#### 1. ❌ 实时数据处理
- **原因**：
  - 无法持续运行
  - 会话结束时进程终止
  - 没有持久化机制
- **示例**：
  - 实时日志监控
  - 股票价格追踪
  - 传感器数据采集
  - 实时告警系统
- **替代方案**：
  - 使用云服务（AWS Lambda、Google Cloud Functions）
  - 部署到服务器运行
  - 使用专门的监控工具

#### 2. ❌ 大规模爬虫
- **原因**：
  - 网络域名白名单限制
  - 执行时间限制
  - 请求速度限制
- **示例**：
  - 爬取1000+网页
  - 持续爬取新闻网站
  - 大量API调用
  - 图片批量下载
- **替代方案**：
  - 使用专门的爬虫框架（Scrapy）在本地运行
  - 使用爬虫服务（ScrapingBee、Apify）
  - 生成爬虫脚本供用户部署

#### 3. ❌ 多媒体编辑
- **原因**：
  - 不能编辑二进制文件
  - 无图像处理能力
  - 无音视频处理能力
- **示例**：
  - 图片裁剪、滤镜、压缩
  - 视频剪辑、转码
  - 音频混音、格式转换
  - PDF页面操作（合并、拆分、旋转）
- **替代方案**：
  - 使用在线工具（Canva、Cloudinary）
  - 调用API（ImageMagick API、FFmpeg服务）
  - 生成处理脚本（使用PIL、FFmpeg命令）

#### 4. ❌ 高频API调用
- **原因**：
  - 网络速度限制
  - 可能触发限流
  - 执行时间限制
- **示例**：
  - 每秒多次API请求
  - 大批量数据同步
  - 高频率价格查询
- **替代方案**：
  - 批量请求合并
  - 使用缓存减少请求
  - 部署到服务器持续运行

#### 5. ❌ 复杂前端开发（除artifacts）
- **原因**：
  - 无法实时预览（除非使用artifacts功能）
  - 无浏览器调试工具
  - 无法测试交互效果
- **示例**：
  - React/Vue组件开发调试
  - CSS样式微调
  - 交互动画调试
  - 响应式设计测试
- **替代方案**：
  - 使用artifacts功能进行原型开发
  - 生成代码在本地开发环境测试
  - 使用在线IDE（CodeSandbox、StackBlitz）

#### 6. ❌ 数据库管理（生产环境）
- **原因**：
  - 无持久化数据库服务
  - 会话结束数据丢失
  - 无备份机制
- **示例**：
  - 生产数据库操作
  - 大规模数据迁移
  - 复杂事务处理
  - 数据库性能调优
- **替代方案**：
  - 生成SQL脚本供手动执行
  - 使用云数据库服务
  - 在测试环境中验证后再应用

#### 7. ❌ 机器学习训练（大模型）
- **原因**：
  - 计算资源有限（GPU限制）
  - 执行时间限制
  - 内存限制
- **示例**：
  - 深度学习模型训练
  - 大规模数据集处理
  - 超参数调优
  - 模型集成
- **替代方案**：
  - 使用云计算平台（AWS SageMaker、Google Colab）
  - 本地GPU服务器训练
  - 生成训练脚本供部署

#### 8. ❌ 系统级运维
- **原因**：
  - 权限限制
  - 无法修改系统配置
  - 无持久化
- **示例**：
  - 修改系统防火墙
  - 配置网络路由
  - 系统性能监控
  - 用户权限管理
- **替代方案**：
  - 生成配置文件和说明
  - 使用IaC工具（Terraform、Ansible）
  - 在本地或服务器手动配置

#### 1. ✅ 文档批量处理
- **优势**：强大的文本处理能力
- **示例**：
  - Markdown文件格式统一
  - 批量添加目录

  - 提取文档中的特定信息
  - 批量重命名和整理
- **最佳实践**：
  - 一次处理50-100个文件
  - 保存中间结果
  - 使用模板确保一致性

#### 2. ✅ 数据清洗整理
- **优势**：灵活的数据处理能力

  - <10000行记录

#### 3. ✅ 代码/脚本生成
- **优势**：理解需求并生成代码
- **示例**：
  - 自动化脚本创建
  - 样板代码生成
  - 配置文件生成

- **优势**：生成规范配置
- **示例**：
  - Docker配置文件

  - 环境配置文件
  - 数据库迁移脚本
  - API文档生成
- **适用场景**：
  - 标准化配置
  - 模板化部署

### 边界场景（谨慎使用）

#### 1. ⚠️ Web内容抓取
- **限制**：仅限白名单域名，可能速度慢
- **可行性**：如果目标在白名单内，小规模抓取可行
- **建议**：
  - 先测试目标域名是否可访问
  - 一次抓取<50个页面
  - 设置重试和错误处理
  - 考虑手动提供内容作为备选

#### 2. ⚠️ 复杂数据分析
- **限制**：中小规模可以，大规模会卡
- **可行性**：<10000行数据，基础统计分析可行
- **建议**：
  - 使用采样数据验证逻辑
  - 分批处理大数据集
  - 避免复杂的机器学习
  - 生成分析脚本供本地运行

#### 3. ⚠️ 多步骤workflow
- **限制**：可以做，但需分段执行
- **可行性**：每段<5分钟，总计<10步可行
- **建议**：
  - 使用TodoWrite工具追踪进度
  - 保存每步中间结果
  - 每步完成后验证
  - 准备好从中断点恢复

#### 4. ⚠️ Git复杂操作
- **限制**：基础操作OK，merge/rebase需小心
- **可行性**：非交互式Git操作可行
- **建议**：
  - 避免git rebase -i等交互式命令
  - merge前充分测试
  - 不要--force push到main分支
  - 有疑问时先在分支上测试

#### 5. ⚠️ 测试运行和调试
- **限制**：可运行测试，但交互式调试受限
- **可行性**：单元测试、集成测试可行
- **建议**：
  - 使用print/logging调试
  - 分段测试代码
  - 查看完整traceback
  - 避免需要GUI的测试

```
任务类型？

│
├─ 网络操作
│  ├─ 白名单域名 → ⚠️ 小规模可以
│  └─ 非白名单 → ❌ 不适合
│
├─ 需要持久化 → ❌ 不适合
│
├─ 需要GUI → ❌ 不适合（artifacts除外）
│
├─ 多媒体处理 → ❌ 不适合
│
└─ 计算密集型 → ❌ 不适合
```

### 快速判断标准

**5个问题快速判断是否适合：**

1. **任务能否在5分钟内完成？**
   - 否 → 需要分解任务

2. **是否需要网络访问非白名单域名？**
   - 是 → 考虑替代方案

3. **是否需要持续运行或后台服务？**
   - 是 → 不适合Claude Code

4. **是否处理二进制文件（图片/视频/音频）？**
   - 是 → 不适合Claude Code

5. **数据量是否<100MB，记录数<10000？**
   - 否 → 需要分批或不适合

**如果5个问题都通过，则非常适合Claude Code！**
