# Claude Code 限制清单

## 技术限制

### 执行环境限制

#### 1. 网络访问
- **限制**：只能访问白名单域名
- **影响**：不能直接爬取大部分网站或调用未授权的API
- **替代方案**：
  - 手动提供网页内容
  - 使用已授权的API
  - 通过WebFetch工具访问（如可用）
  - 在本地下载后再处理
- **已知可访问域名示例**：
  - api.anthropic.com
  - github.com
  - pypi.org
  - npmjs.com
  - 各类文档站点

#### 2. 文件大小
- **限制**：
  - 单文件建议<1MB（超大文件会被截断）
  - 单行字符限制：2000字符
  - PDF文件：最大32MB，每次请求最多100页
  - 总行数有限制（具体视文件而定）
- **影响**：不适合处理大型数据文件、日志文件、大型JSON等
- **替代方案**：
  - 分批处理（读取部分行）
  - 使用流式读取
  - 拆分大文件为多个小文件
  - 使用offset和limit参数分段读取

#### 3. 执行时间
- **限制**：
  - 默认超时：2分钟
  - 最长超时：10分钟（可配置）
  - 长时间运行可能超时或被中断
- **影响**：不适合耗时任务（如大规模爬虫、长时间计算、大量文件处理）
- **替代方案**：
  - 分解为多个小任务
  - 保存中间结果
  - 使用批处理策略
  - 后台执行（run_in_background）但会话结束时终止

#### 4. 并发限制
- **限制**：
  - 工具调用是串行的（一个接一个）
  - 单个命令内可以用&或&&链接多个操作
  - 不能真正并行执行多个独立任务
- **影响**：串行执行效率较低，大批量任务耗时
- **替代方案**：
  - 在单个Bash命令中使用&实现伪并发
  - 优化任务顺序
  - 设计高效的批量处理流程

#### 5. 持久化
- **限制**：
  - 无法运行持久化后台服务
  - 会话结束时所有进程终止
  - 没有数据库服务（除非已安装并启动）
- **影响**：
  - 不能做持续监听任务
  - 不能做定时任务
  - 不能运行Web服务器供长期访问
- **替代方案**：
  - 使用外部cron服务
  - 使用云服务（如AWS Lambda）
  - 生成配置文件供用户手动部署
  - 使用systemd等系统服务（需要权限）

#### 6. 计算资源限制
- **限制**：
  - GPU算力有限（按小时滚动窗口和每周分配上限）
  - CPU和内存受限
  - 不适合计算密集型任务
- **影响**：
  - 机器学习训练受限
  - 大规模数据处理可能卡顿
  - 复杂算法可能超时
- **替代方案**：
  - 使用云端计算平台
  - 简化算法
  - 使用采样而非全量数据
  - 生成代码供用户在本地运行

### 文件操作限制

#### 1. 二进制文件
- **限制**：不能编辑图片、音视频、Office文件等二进制内容
- **影响**：
  - 无法做图像处理（裁剪、滤镜等）
  - 无法视频剪辑或音频编辑
  - 无法直接修改.docx、.xlsx、.pptx
- **替代方案**：
  - 调用外部工具API（如ImageMagick、FFmpeg）
  - 使用在线服务API
  - 对于Office文件，先转换为XML或其他文本格式
  - 生成处理脚本供用户执行

#### 2. 文件权限
- **限制**：
  - 某些系统文件无法访问
  - sudo权限受限
  - 不能修改系统核心配置
- **影响**：
  - 不能安装某些需要系统权限的软件
  - 不能修改/etc/下的配置
  - 不能修改系统级环境变量
- **替代方案**：
  - 操作用户目录文件
  - 使用用户级包管理（如pip --user）
  - 修改用户级配置文件（~/.bashrc等）
  - 生成说明供用户手动执行需要权限的操作

#### 3. 格式支持
- **限制**：
  - 不能直接处理Office文件（.docx, .xlsx, .pptx）
  - 某些专有格式不支持
  - 压缩文件需要先解压
- **影响**：需要格式转换的额外步骤
- **替代方案**：
  - 使用转换库（python-docx、openpyxl等）
  - 使用在线转换API
  - 让用户导出为CSV、JSON等标准格式
  - 读取Office文件的XML结构

#### 4. 文件编辑方式
- **限制**：
  - Edit工具只能精确字符串替换
  - 如果old_string不唯一会失败
  - 不支持正则表达式替换（通过Edit工具）
- **影响**：某些复杂编辑需要多步操作
- **替代方案**：
  - 使用replace_all批量替换
  - 提供更多上下文使old_string唯一
  - 使用sed/awk等工具（通过Bash）
  - 读取→修改→写入整个文件

### 代码执行限制

#### 1. 包管理
- **限制**：
  - 第三方库需要手动安装
  - 某些包可能因为系统依赖无法安装
  - 安装可能需要时间和网络
- **影响**：不能直接使用所有Python/Node包
- **替代方案**：
  - 先安装再使用（pip install、npm install）
  - 使用标准库替代
  - 生成requirements.txt供用户安装
  - 检查是否已安装

#### 2. 交互式命令
- **限制**：
  - 不支持需要用户输入的交互式命令
  - 如git rebase -i、vim、nano等
  - 无法处理提示输入密码的情况
- **影响**：某些高级Git操作受限，某些工具无法使用
- **替代方案**：
  - 使用非交互式参数
  - 预先配置（如git config）
  - 使用-y或--yes跳过确认
  - 通过环境变量传递凭证

#### 3. 资源限制
- **限制**：
  - 内存有限
  - CPU有限
  - 无GPU加速（或GPU使用受限）
- **影响**：不适合计算密集型任务
- **替代方案**：
  - 简化算法（如使用近似算法）
  - 减小数据规模
  - 使用云端计算
  - 生成代码供用户在更强机器上运行

#### 4. 调试限制
- **限制**：
  - 无法使用交互式调试器（如pdb、ipdb）
  - 无法设置断点逐步调试
  - 错误信息可能不完整
- **影响**：复杂bug可能难以定位
- **替代方案**：
  - 使用print/logging调试
  - 分段执行代码
  - 单元测试
  - 分析traceback和日志

### Web交互限制

#### 1. 域名白名单
- **限制**：大部分网站无法直接访问
- **影响**：
  - 不能爬取任意网站
  - 不能调用大多数公开API（除非在白名单）
  - 不能下载任意资源
- **替代方案**：
  - 使用WebFetch工具（如可用）
  - 用户手动提供内容
  - 使用已授权的API
  - 检查域名是否在白名单

#### 2. 访问速度
- **限制**：网络请求可能较慢或超时
- **影响**：
  - 大文件下载可能失败
  - 多次请求耗时长
  - API调用可能超时
- **替代方案**：
  - 设置重试机制（指数退避）
  - 增加超时时间
  - 使用缓存避免重复请求
  - 批量请求合并

#### 3. 认证和授权
- **限制**：
  - API密钥需要在环境中配置
  - 某些认证方式可能不支持（如OAuth流程）
  - 敏感信息管理受限
- **影响**：某些需要复杂认证的API难以使用
- **替代方案**：
  - 使用环境变量传递密钥
  - 简化认证流程
  - 使用token而非密码
  - 让用户在本地配置认证

### 跨文件依赖限制 *（来源：官方文档）*

#### 1. 大型项目理解
- **限制**：
  - 在大型项目中可能遗漏跨文件依赖
  - 可能误解模块级逻辑
  - 不能一次性理解所有代码
- **影响**：
  - 修改可能破坏其他模块
  - 重构可能不完整
  - 依赖关系可能被忽略
- **替代方案**：
  - 明确指出相关文件和依赖
  - 分步骤进行修改和验证
  - 使用Task工具进行代码探索
  - 提供架构文档或依赖图

#### 2. 领域知识限制 *（来源：官方文档）*
- **限制**：
  - 不能替代特定领域的专业知识
  - 遵循编程模式但不理解业务逻辑（除非明确说明）
  - 可能建议看似正确但有边界情况错误的代码
  - 可能引入微妙的bug
- **影响**：关键业务逻辑需要人工审查
- **替代方案**：
  - 详细说明业务规则
  - 提供测试用例
  - 代码审查
  - 明确边界条件

### Token使用限制

#### 1. 上下文窗口
- **限制**：
  - Token总量有限（当前预算：200000）
  - 大量文件读取会快速消耗token
  - 长对话可能达到上限
- **影响**：
  - 不能一次性处理大量文件
  - 复杂任务可能需要多个会话
  - 历史对话可能被截断
- **替代方案**：
  - 分批处理文件
  - 新会话继续任务
  - 只读取必要部分
  - 使用Task工具（独立token预算）

#### 2. 输出截断
- **限制**：
  - 命令输出>30000字符会截断
  - 文件读取有行数限制
- **影响**：大文件或大量输出看不全
- **替代方案**：
  - 使用head/tail限制输出
  - 分段读取文件
  - 将输出保存到文件
  - 使用grep等过滤工具
