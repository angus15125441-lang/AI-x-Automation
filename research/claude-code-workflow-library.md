# Claude Code Workflow Library

> 全面的 Claude Code 自动化工作流库，帮助你快速找到适合场景的工作流模板

## 项目概述

本文档整理了适用于 Claude Code 的各类自动化工作流，涵盖文档处理、数据分析、内容创作等多个领域。每个工作流都包含完整的输入、步骤、输出说明和可复用的提示词片段。

## 按难度分级

### 新手友好（低难度）- 5个
快速上手，适合初学者

1. **批量Markdown文件整理** (1.1) - 文档处理类
   - 统一格式规范，自动修复常见问题
   - 时间节省: 120min → 8min

2. **文档格式转换与增强** (1.3) - 文档处理类
   - 日志转Markdown，添加格式增强
   - 时间节省: 60min → 4min

3. **结构化内容批量生成** (3.1) - 内容创作类
   - 基于数据源批量生成内容
   - 时间节省: 200min → 7min

4. **多版本内容批量创建** (3.2) - 内容创作类
   - 同一内容多风格改写
   - 时间节省: 120min → 5min

5. **JSON数据结构化整理** (2.2) - 数据处理类
   - 嵌套JSON扁平化
   - 时间节省: 80min → 3min

### 进阶应用（中难度）- 7个
需要一定数据处理和AI应用经验

6. **多文件信息提取与汇总** (1.2) - 文档处理类
   - 从多文档提取关键信息
   - 时间节省: 90min → 5min

7. **CSV数据清洗与分析** (2.1) - 数据处理类
   - 数据质量检测和统计分析
   - 时间节省: 150min → 6min

8. **文本数据批量处理与分类** (2.3) - 数据处理类
   - 主题分类和情感分析
   - 时间节省: 240min → 10min

9. **网络信息收集与整理** (4.1) - 研究与知识管理类
   - 批量网页抓取和信息提取
   - 时间节省: 180min → 12min

10. **文献资源分类索引构建** (4.2) - 研究与知识管理类
    - 建立文献分类索引系统
    - 时间节省: 300min → 15min

11. **项目需求任务分解** (5.1) - 项目管理类
    - 需求分析和任务拆解
    - 时间节省: 180min → 10min

12. **项目文档自动生成** (5.2) - 项目管理类
    - 根据代码生成完整文档
    - 时间节省: 240min → 15min

### 高级技巧（高难度）- 1个
复杂场景，需要深度AI能力

13. **个人知识库自动构建** (4.3) - 研究与知识管理类
    - 散乱笔记转结构化知识库
    - 时间节省: 400min → 20min

## 按输入类型索引

### 文件输入类（9个）
需要读取本地文件作为输入

- **1.1 批量Markdown文件整理** - 多个.md文件
- **1.2 多文件信息提取与汇总** - 多种格式文档
- **1.3 文档格式转换与增强** - .txt/.md/.log文件
- **2.1 CSV数据清洗与分析** - CSV文件
- **2.2 JSON数据结构化整理** - JSON文件
- **2.3 文本数据批量处理** - CSV/TXT文件
- **4.2 文献资源分类索引** - PDF/Markdown/TXT
- **4.3 个人知识库构建** - 多个笔记文件
- **5.2 项目文档自动生成** - 代码库目录

### 混合输入类（3个）
需要文件+配置或模板

- **3.1 结构化内容批量生成** - 数据源 + 内容模板
- **3.2 多版本内容批量创建** - 原始内容 + 版本需求
- **5.1 项目需求任务分解** - 需求文档

### URL输入类（1个）
需要网络链接作为输入

- **4.1 网络信息收集与整理** - URL列表文件
